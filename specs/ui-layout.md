## 一、总体布局

```
+---------------------------------------------------------------+
|  顶部标题栏（44px）                                             |
|  [☰ 折叠侧边栏] [任务名称]   [企业智能体] [面板开关] [状态指示器] |
+----------+----------------------------------------------------+
|          |                                                    |
|  左侧    |            中间主内容区                              |
|  侧边栏  |    （根据 activeView 动态切换不同面板）              |
| 240px    |                                                    |
|          |                                              +-----+
|          |                                              |右侧 |
|          |                                              |结果 |
|          |                                              |面板 |
|          |                                              |40%  |
|          |                                              |     |
+----------+----------------------------------------------+-----+
|  状态栏: BspBuddy v0.1.0                     [● Ready/Processing] |
+---------------------------------------------------------------+
```

### 区域划分

| 区域 | 宽度 | 说明 |
|------|------|------|
| 左侧侧边栏 | 240px | 可折叠；任务列表、搜索、状态筛选、功能导航入口 |
| 顶部标题栏 | 100% × 44px | 汉堡菜单、会话标题、面板开关+状态 |
| 中间主内容区 | flex:1 | 根据 `activeView` 动态渲染对应功能面板 |
| 右侧结果面板 | 40% | 仅在 chat 视图中显示；可折叠；四 Tab 切换 |
| 底部状态栏 | ✅ 已实现 | 版本号 BspBuddy v0.2 + Ready/Processing 状态 |

## 二、左侧侧边栏 (Sidebar)

```text
+---------------------------+
|  [🔔 铃铛]   [+ 新建任务]   |  ← 铃铛（disabled）+ 新建按钮
+---------------------------+
|  [任务] [空间]  ← Tab      |
+---------------------------+
|  [🔍 搜索任务...]          |
|  [▾ 状态筛选: 全部▾]       |  ← 下拉：全部/进行中/已完成/失败/待处理/规划中/已归档
+---------------------------+
|  ▼ 任务列表                |
|   📄 任务卡片 1            |
|     〃标题〃 时间 ● 进行中  |  ← 卡片显示状态颜色圆点 + 标签
|   📄 任务卡片 2            |
|     〃标题〃 时间 ● 已完成  |
+---------------------------+
|  ▼ 工作空间分组             |
|   📁 Default              |
|   📁 空间A / 空间B         |
+---------------------------+
|  导航入口:                 |
|   [🧩 插件]                |  ← Puzzle 图标
|   [👥 专家]                |  ← Users 图标
|   [🔗 连接器]              |  ← Link 图标
|   [🏢 项目]                |  ← Building2 图标
|   [··· 更多 ▾]             |  ← MoreHorizontal, 展开→"我的邮箱"
+---------------------------+
|  底部:                    |
|   [U]  User  ← 用户头像    |  ← 点击→弹出菜单：设置/记忆/定价/数据管理
+---------------------------+
```

### 侧边栏详细说明

| 组件 | 说明 |
|------|------|
| **头部区** | 通知铃铛（disabled）+ 新建任务按钮（accent 蓝色背景） |
| **Tab 切换** | 「任务」— 展示任务列表（标题+时间+状态标签）；「空间」— 按工作空间分组 |
| **搜索框** | 关键字过滤任务标题，placeholder: "搜索任务..." |
| **状态筛选** | 下拉 select：全部/进行中/已完成/失败/待处理/规划中/已归档（6种） |
| **任务卡片** | 点击进入该任务对话；显示状态颜色圆点+标签；右键菜单支持 7 项：置顶/打开文件夹/重命名/保存到工作空间/分享/删除/归档 |
| **导航入口** | 4 个主导航：插件(Puzzle)/专家(Users)/连接器(Link)/项目(Building2)；更多▾ 展开→我的邮箱 |
| **用户头像区** | 底部用户圆形头像（"U" 占位），点击弹出菜单：设置/记忆/定价/数据管理 |
| **折叠** | 点击汉堡菜单 ☰ → `collapsed=true`，侧边栏缩为 52px 窄图标栏 |

## 三、顶部标题栏 (44px)

```
[☰] [Session 标题]          [企业智能体] [Panel On/Off] [● Ready]
```

| 元素 | 说明 |
|------|------|
| **汉堡按钮 ☰** | 折叠/展开侧边栏 |

#### 4.1.1 空状态 — WelcomeScreen
- 🔴 文档说 4 个示例提示词，实际代码有 **7 个技能卡片**（Word文档/Excel表格/PPT演示/PDF处理/搜索资料/浏览网页/邮件处理）
- 居中大 W logo + "BspBuddy" 标题 + 中文副标题「你的 AI 办公助手...」
- 🔴 文档描述为英文 "Describe what you need..."，实际是中文

#### 4.1.2 对话消息
- 用户消息：右对齐，蓝色气泡
- AI 回复：左对齐，灰色气泡，内置 Task Plan 步骤展开（Sparkles 图标 + 步骤列表）
- 🟡 无"系统消息"(红色背景提示条) — 文档有描述但代码未实现
- 🟡 AI 回复中含 artifacts 时，无底部文件列表 — 文档描述但代码未实现

#### 4.1.3 输入区域 — 由上到下
| 组件 | 说明 |
|------|------|
| **ModeSwitch** | Ask(仅问答) / Craft(直接执行) / Plan(先生成计划) 三按钮切换 |
| **ModelSelector** | 下拉菜单：MiniMax / 智谱GLM / Kimi / DeepSeek / 腾讯混元 |
| **UploadZone** | 已选文件显示 chips，支持拖拽、Ctrl+V 粘贴图片、@ 引用文件、托盘按钮上传 |
| **PermissionSelector** | 默认权限 (沙箱) / 完全放开 |
| **工作空间文件夹图标** | 点击打开系统文件选择器，选中路径显示在下方 |
| **停止按钮** | `isProcessing` 时发送→变为红色方块停止按钮 |
| **示例提示词** | 无消息时在输入框上方显示快捷入口 |

#### 4.1.4 关于 ChatPanel 更完整布局（当 hasMsg=true）

**顶栏（对话内）：** 🟡 SPEC 描述 4 项功能，实际只实现 1 项
- ✅ 已实现：搜索按钮（对话内容关键词搜索）
- 🟡 未实现：**分享任务**按钮 — 文档描述自动生成公开链接，代码中没有此按钮

**Timeline（执行时间线）：** ✅ 已实现
- 每个 step 显示为行：状态图标 + 描述 + 状态
- running: 旋转动画，completed: 绿色勾，failed: 红色叉

### 5.1 产物 Tab (ArtifactView)
- Agent 生成的交付物列表
- 显示：文件名 + 类型图标 + 大小
- 支持的产物格式：`.md` `.docx` `.pptx` `.html` `.xlsx` `.pdf` 等
- 🔴 **下载和内联预览按钮无 click handler** — 视觉上存在但功能未实现
- 🟡 「打开文件夹」入口 — 文档描述但代码无此按钮

### 5.2 浏览器 Tab (BrowserPreview)
- 🔴 文档说 Electron `<webview>` 标签，实际使用 `<iframe sandbox>` 标签
- 🟡 文档说显示当前页面地址 + 刷新按钮，实际只渲染 iframe 无地址栏

### 5.3 变更 Tab (DiffView)
- 🔴 **严重差异** — 文档描述完整 diff：左侧文件列表 + 右侧 diff 对比 (originalContent vs newContent)
- 实际代码仅显示**数字统计列表**：`filePath + description + addedLines/removedLines`，无内容 diff
- 🟡 且 `changes` 数组始终传 `[]`（`<DiffView changes={[]} />`），该 Tab 永远为"无变更"空状态

### 5.4 文件 Tab (WorkspaceFiles)
- 左侧：工作空间文件树（基于 workspacePath 递归读取）
- 右侧：选中文件内容预览
- 顶部：已打开文件标签切换栏
- 🟡 该组件仅在 ResultPanel 中渲染，但 `ResultPanel` 仅在 `activeView === 'chat'` 时可见 — 文件 Tab 功能受限
