# WorkBuddy 接入元宝派指南

> 来源: https://www.codebuddy.cn/docs/workbuddy/YuanBaoPai-Guide
> 抓取: 2026-08-03

---

元宝机器人集成让您可以将 WorkBuddy 添加到元宝的社区圈子（派）中，与群友共享。| 元宝派的 Bot 既可以在私聊中使用，也可以加入派中参与群聊。

## 元宝机器人能做什么

- 在派内 @机器人下发任务，结果返回给全派成员可见
- 直接向机器人发送任务指令，私聊内容仅自己可见
- 将机器人添加到已有的派，在群聊中直接使用
- 派内成果共享：生成的方案、报告、设计稿等产出物实时共享
- 批准命令执行、文件修改等需要确认的操作

## 设置前的准备

| 要求 | 说明 |
|------|------|
| WorkBuddy | >= 4.6.4 |
| 腾讯元宝 App | 已安装并完成登录 |
| 网络连接 | 电脑和手机均能正常访问互联网 |

## 连接元宝派

### 第一步：在元宝 App 中创建 Bot

1. 打开腾讯元宝 App
2. 底部导航栏「派」标签 → 顶部「Bot」
3. 点击「关联已有 QpenClaw」进入关联配置页面
4. 当前已支持扫码关联 WorkBuddy；也可通过手动配置获取 AppID 和 AppSecret

### 第二步：在 WorkBuddy 中完成绑定

1. WorkBuddy → 左下角头像 →「设置-助理设置」
2. 元宝扫码绑定处完成扫码 OR 找到「元宝机器人集成」→「配置」
3. 将 AppID 填入 App Key、AppSecret 填入 App Secret → 点击注册

### 第三步：在元宝 App 中完成关联

回到元宝 App 关联页面 → 点击「我已操作」→ 关联成功后可「开始聊天」或「添加到已有的派」

## 开始使用

- 私聊测试：先在私聊窗口向机器人发送任务
- 派内协作：将机器人添加到派中，@机器人发布任务，全派围观执行过程
