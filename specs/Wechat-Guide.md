# WorkBuddy 接入微信客服号指南

> 来源: https://www.codebuddy.cn/docs/workbuddy/Wechat-Guide
> 抓取: 2026-08-03

---

微信客服号集成让您可以通过手机微信远程控制电脑上的 WorkBuddy。绑定流程为扫码即可完成，无需额外创建开放平台应用，也不需要填写 App ID、App Secret 等开发凭证。

## 设置前的准备

| 要求 | 说明 |
|------|------|
| WorkBuddy | macOS / Windows >= 4.6.4 |
| 微信 | 手机上 >= 8.0.70 |
| 网络 | 电脑和手机均能正常访问互联网 |

## 连接微信客服号

### 第一步：打开助理设置

WorkBuddy → 右上角头像 →「助理设置」→「微信客服号集成」→「配置」

### 第二步：等待绑定初始化

点击配置后，按钮短暂显示为「绑定中...」，系统正在生成绑定二维码。

### 第三步：扫码完成绑定

初始化完成后展示二维码 → 手机微信扫描 → 显示已绑定的微信头像和昵称 → 状态变为「已绑定」

二维码有时效限制，过期请重新点击配置生成新的。

## 使用示例

- 帮我总结今天桌面上最新的会议记录
- 帮我检查这个项目最近改过的接口有没有明显问题
- 帮我生成一个登录页原型

WorkBuddy 会在电脑上自动执行任务，并把执行过程和最终结果同步回微信聊天窗口。

## 跨设备接续工作

- 微信发起任务后可回到电脑 WorkBuddy 查看完整执行过程
- 助理页面可查看远程任务的完整执行记录（思考过程、操作步骤、生成文件及最终结果）
- 可在电脑上继续追问、细化任务

## 本地电脑的作用

| 来源 | 说明 |
|------|------|
| 手机微信 | 仅发送指令、批准操作和后续消息 |
| 您的电脑 | 提供执行所需的全部环境 |

## 微信客服号和微信助理的区别

两者功能相同，都可以通过微信与 WorkBuddy 对话。微信客服号是 WorkBuddy 提供的绑定通道之一，微信助理是另一种绑定通道。绑定流程一致，您可以根据需要选择其中一种使用。
