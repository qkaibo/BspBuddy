# 17 — 数据管理 + 系统设置 (Data + Settings)

> 对应 SPEC: `specs/From-Beginner-to-Expert-Guide/Data.md`, `specs/From-Beginner-to-Expert-Guide/Setting.md`
> Status: ❌ P3 待开发

## 一、数据管理 (Data)

**入口**: 头像 → 设置 → 数据管理

### 我分享的文件

- 任务产物分享后 → 出现此列表
- 操作: 复制分享链接 / 下载 / 取消分享
- 取消分享后文件从列表移除，他人无法再通过链接访问

### 已归档任务

- 任务列表归档后 → 出现此列表
- 操作:
  - 删除: 弹窗二次确认 → 任务不可查看/不可继续对话
  - 取消归档: 恢复到任务列表

## 二、系统设置 (Settings)

**入口**: 头像 → 设置 → 系统设置

### 语言
- 中文(简体) / English

### 字体大小
- 调整对话和界面字体大小

### 简洁模式
- **默认开启** (ON → 用户可手动关闭)
- 行为: **视觉层面变化** — 简化对话界面显示，隐藏装饰性元素，折叠对话中工具调用等过程信息
- 区别于结构性变化，仅影响 UI 简洁度

### 非高风险自动安装
- 上传 Skill 后显示安全检测过程
- 非高风险: 自动继续安装
- 高风险: 始终需要手动确认

### 防休眠
- 开启后电脑不进入休眠
- 用途: 方便手机远程操控、自动化任务持续进行

## 三、实现任务 (实现细节)

### 17-1 数据管理页面 (`src/components/DataPanel.tsx`)

```
头像 → 设置 → 数据管理
├── 我分享的文件
│   ├── 列表显示: 文件名 + 分享时间
│   ├── 按钮: 复制链接 / 下载 / 取消分享
├── 已归档任务
│   ├── 列表显示: 任务名 + 归档时间
│   ├── 按钮: 删除(二次确认) / 取消归档
```

### 17-2 系统设置页面 (`src/components/SettingsPanel.tsx`)

```
头像 → 设置 → 系统设置
├── 语言选择 (中文/English)
├── 字体大小滑块
├── 简洁模式开关 (默认ON)
│   └── ON: 隐藏装饰性元素 + 折叠工具调用过程
├── 非高风险自动安装
│   ├── 非高风险: 自动继续
│   ├── 高风险: 手动确认
├── 防休眠开关
```

## 四、验收标准

- [ ] 分享产物 → 数据管理已分享列表可见 → 复制链接/下载/取消分享
- [ ] 取消分享后 → 链接失效
- [ ] 归档任务 → 已归档列表可见 → 删除(二次确认)/取消归档
- [ ] 简洁模式默认 ON → 界面隐藏装饰元素 + 折叠工具调用
- [ ] 切换语言 → 界面立即刷新
- [ ] 字体大小滑块 → 对话字体实时变化
- [ ] 防休眠开启 → 电脑不自动休眠
