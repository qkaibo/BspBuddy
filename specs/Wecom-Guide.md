# WorkBuddy 接入企业微信指南

> 来源: https://www.codebuddy.cn/docs/workbuddy/Wecom-Guide
> 抓取: 2026-08-03

---

企微助理集成让您可以通过企业微信远程控制电脑上的 WorkBuddy。

## 企微助理能做什么

- 在群聊中 @机器人下发团队协作任务
- 直接向机器人发送任务指令，随时跟进执行进度
- 创建专属任务群，长期绑定 WorkBuddy 处理团队日常工作
- 发布通知、任务提醒、流程打通
- 批准命令执行、文件修改等需要确认的操作

## 设置前的准备

| 要求 | 说明 |
|------|------|
| WorkBuddy | >= 4.6.4 |
| 企业微信账号 | 拥有可创建智能机器人的企业微信账号 |
| 网络连接 | 电脑和手机均能正常访问互联网 |

## 连接企微助理（长连接模式—推荐）

### 管理员操作

1. 企业微信管理后台 →「安全与管理」→「管理工具」→「智能机器人」→「创建机器人」
2. 选择「API 模式创建」
3. 填写机器人名称和可见范围 → 保存 → 选择「使用长连接」
4. 复制 Bot ID 和 Secret

### 普通成员操作

1. 企业微信客户端 →「工作台」→「智能机器人应用」→「创建机器人」
2. 选择「API 模式创建」→ 填写名称和可使用成员
3. 选择「使用长连接」→ 复制 Bot ID 和 Secret

### 在 WorkBuddy 中完成绑定

1. 打开 WorkBuddy → 设置-助理设置 →「企微助理集成」→「配置」
2. 选择「WebSocket 长连接」
3. 两种绑定方式：手动填写 Bot ID 和 Secret 或企微扫码快捷绑定
4. 填入凭据后点击注册完成

### 使用 URL 回调接入（备选方案）

1. 企业微信侧选择「使用 URL 回调」→ 随机获取 Token 和 Encoding-AESKey
2. WorkBuddy 侧切换到「使用 URL 回调」→ 填入凭据 → 注册 → 复制生成的 Webhook URL
3. 回到企业微信粘贴 URL → 保存

## 开始使用

企业微信通讯录中「企业创建的」分组下找到机器人 → 点击「发消息」即可下发任务。
