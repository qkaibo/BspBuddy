# WorkBuddy 接入飞书指南

> 来源: https://www.codebuddy.cn/docs/workbuddy/Feishu-Guide
> 抓取: 2026-08-03

---

本指南将帮助您在飞书中配置 WorkBuddy 机器人，让您可以通过飞书随时随地远程操控电脑上的 WorkBuddy 完成编程任务。

## 前提条件

- 已在电脑上安装 WorkBuddy，并开启了助理远程控制功能
- 拥有一个飞书企业账号（需要有创建应用的权限）

## 配置步骤

### 1. 创建飞书应用

访问飞书开放平台 → 使用企业账号登录 →「创建企业自建应用」

### 2. 配置权限

应用详情页 →「权限管理」→「批量导入/导出权限」

### 3. 获取凭证

获取 App ID、App Secret 及 Encrypt Key。

### 4. 在 WorkBuddy 中配置飞书

打开 WorkBuddy → 助理设置 → 飞书集成 → 填入 App ID、App Secret、Encrypt Key

两种连接模式：
- **WebSocket 长连接模式（推荐）**：适用于个人/家庭/办公室用户（没有公网 IP），配置更简单
- **URL 回调模式**：适用于有服务器、有公网 IP 的用户

### 5. 配置飞书事件回调

返回飞书开放平台 → 应用详情页 →「事件与回调」

- WebSocket 长连接：选择「使用长连接接收事件」→ 验证
- URL 回调：粘贴 Webhook 地址 → 保存

添加事件：搜索并添加「接收消息」事件。

配置卡片回传交互：切换到「回调配置」→ 搜索「卡片回传交互」→ 确认添加
