# WorkBuddy 接入微信助理指南

> 来源: https://www.codebuddy.cn/docs/workbuddy/WeixinBot-Guide
> 抓取: 2026-08-03

---

接入微信助理让您可以通过手机微信远程控制电脑上的 WorkBuddy。无需填写 App ID、App Secret 等开发凭证，只需扫码即可完成绑定。

## 微信助理能做什么

- 启动新的任务，或继续助理板块中未完成的会话
- 发送后续指令、回答 WorkBuddy 的追问、指导进行中的工作
- 批准命令执行、文件修改等需要确认的操作
- 查看任务输出、差异对比
- 当 WorkBuddy 完成任务或需要您的关注时，在微信中收到通知

## 设置前的准备

| 要求 | 说明 |
|------|------|
| WorkBuddy 版本 | macOS / Windows >= 4.6.4 |
| 微信版本 | 手机上 >= 8.0.70 |
| 账号一致性 | WorkBuddy 和微信使用同一账号登录（或已关联） |
| 网络连接 | 电脑和手机均能正常访问互联网 |
| WorkBuddy 运行中 | WorkBuddy 必须保持运行状态 |

## 连接微信助理

### 第一步：打开助理设置

打开 WorkBuddy → 左侧助理栏齿轮图标 →「助理设置」→「微信助理集成」→「配置」

### 第二步：生成并扫码完成绑定

点击配置后生成二维码 → 打开手机微信扫码即可绑定 → 状态变为「已绑定」

二维码有时效限制，过期可重新生成。

## 跨设备接续工作

- 在微信中发起任务后，回到电脑 WorkBuddy 查看完整执行过程和结果
- WorkBuddy 会在助理中显示微信中发起的会话，无需手动查找
- 可在电脑上继续追问、细化任务

## 什么来自本地电脑

| 来源 | 说明 |
|------|------|
| 手机微信 | 仅发送指令、批准操作和后续消息 |
| 您的电脑 | 提供 WorkBuddy 执行任务所需的全部环境 |

电脑上的：项目与文件、Shell 命令、凭证与权限、插件与工具、安全策略均适用远程会话。

## 支持的消息类型

- 文字消息：发送自然语言任务指令
- 图片消息：发送截图或文档照片
- 文件消息：转发文件
- 语音消息：发送语音指令（需微信语音转文字功能）
