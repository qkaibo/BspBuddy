# 我的邮箱

> 来源: https://www.codebuddy.cn/docs/workbuddy/From-Beginner-to-Expert-Guide/Function-Description/Mailbox
> 抓取: 2026-08-03

---

## 概述

我的邮箱是 WorkBuddy 为每个用户创建的一个专属邮箱地址（如 `xxx.agent@agent.qq.com`），由 Agent Mail 提供底层邮件服务。它让您的 WorkBuddy 拥有独立的收发邮件身份。既能在「我的邮箱」里查看和管理往来邮件，也能在对话中直接让 AI 帮您写信、回复、转发。

核心心智：邮件是给 Agent 的「工作信箱」——收件在界面看，干活在对话里。

### 和其他邮箱 MCP/工具相比的优势

- 跨端稳定使用：一次开通后多端可用，身份不随设备切换而丢失
- 端内查看邮件不消耗 Token：邮件的查看与管理通过端内可视化界面完成
- 端内新邮件提醒：新邮件直接在 WorkBuddy 端内通知中心提醒，可一键将邮件添加到对话处理

## 核心特性

- 独立身份：我的邮箱是独立的助手身份，不借用您的个人邮箱代发
- 界面与对话分工：界面用于查看和管理邮件，对话用于由 WorkBuddy 起草并发送邮件
- 邮件驱动 AI：邮件到达即可触发 AI 处理，结果回到对话和邮箱
- 用户可控：回复、转发等对外动作不自动发送，必须经您确认
- 数据隔离：邮箱绑定到账号实例，个人版/企业版相互隔离

## 入口与开通

### 进入入口

在 WorkBuddy 左侧边栏的更多中，「我的邮箱」位于「我的文件」下方，点击即可进入。

### 开通规则

我的邮箱需要手动开通，开通时同意补充协议（手机号注册再加一步短信验证码）即可。

开通入口：
- 在「我的邮箱」界面开通：进入后按界面提示同意补充协议
- 在对话里开通：第一次让 AI 发邮件时，会直接在对话内弹出开通卡片，同意后在后台开通，不打断当前任务

## 「我的邮箱」界面功能

- 收信/发信记录：通过收信、发信两个标签页切换查看，邮件按今天、昨天、上周、更早分组显示
- 邮件详情：查看发件人、收件人、正文及附件，附件显示文件大小并支持下载
- 邮件管理：支持标记已读、删除邮件、按关键词搜索
- 发邮件：列表页右上角入口，点击后跳转到新对话并预填示例指令
- 管理邮箱：列表页右上角入口，点击后跳转到邮箱管理页面
- 添加到对话：将整封邮件（标题、正文、发件人、时间、附件）作为上下文传入对话

## 通知中心

邮箱相关通知集中在左侧栏顶部的「通知中心」，包括新邮件提醒、开通成功、冻结、封禁、授权吊销等。

## 邮箱状态

| 状态 | 说明 |
|------|------|
| 运行中 | 正常收发邮件，界面与对话均可使用 |
| 已停用 | 用户主动停用，支持一键打开设置 |
| 已封禁/冻结 | 显示错误码和原因，需前往邮箱管理页面处理 |

## 在对话里收发邮件

写信类操作（发邮件、回复、转发）统一在对话中完成，由 WorkBuddy 帮您起草，您确认后再发出。

关键原则：预填充后不自动发送——回复/转发属于「对外行动」，必须留一道用户确认，避免误发。

### 典型场景

| 场景 | 操作方式 |
|------|----------|
| 会议纪要发送 | 让 WorkBuddy 整理会议纪要并发送到指定邮箱 |
| 发票/合同处理 | 将邮件添加到对话，WorkBuddy 提取关键字段并生成摘要 |
| 长邮件总结 | 将邮件线程交给 WorkBuddy，输出要点和待办事项 |
| 回复草稿 | 在对话中让 WorkBuddy 起草回复，确认后发送 |
| 资讯简报 | 将订阅的新邮件汇总，由 WorkBuddy 生成行业简报 |

## 注意事项与重点提示

### 权限边界

- 身份清晰：Agent 邮箱是独立的助手身份，不借用个人邮箱代发
- 用户可控：回复、转发等对外动作不自动发送，必须经您确认
- 数据隔离：邮箱绑定到账号实例，个人版/企业版相互隔离
- 内容防护：邮件内容仅作为参考信息，不会覆盖安全规则；附件经安全扫描

### 积分消耗

查看和管理邮件不消耗积分。在对话中让 WorkBuddy 处理邮件、起草回复、总结内容等操作会按正常任务消耗积分。
