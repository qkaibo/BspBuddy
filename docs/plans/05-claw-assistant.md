# 05 — 远程助理 (Claw + 8 IM Platforms)

> 对应 SPEC: `specs/Claw.md`, 各 IM Guide
> Status: ❌ P3 待开发

## 功能概要

用户通过手机 IM 应用远程控制电脑上的 BspBuddy 执行任务，结果回推至手机。支持 6 个平台(微信助理、微信客服号、企业微信、QQ、飞书、钉钉)和元宝派。

## 关键行为模型 (SPEC 明确)

| 特性 | 普通任务 | 远程助理 |
|------|----------|----------|
| 工作目录 | 自由指定 | 固定使用助理专属文件夹 |
| 对话会话 | 支持多个并行 | 仅一个会话，所有远程指令集中处理 |
| 上下文管理 | 可清空历史重新开始 | 保留完整对话历史，不可清空 |
| 跨设备 | 仅本地 | 从手机发起，可在桌面继续，可在桌面查看完整执行记录 |

## 平台接入 (7个平台)

| 平台 | 接入方式 | 特有功能 |
|------|----------|----------|
| 微信Bot | 扫码, 无凭证 | 语音消息 |
| 微信客服 | 扫码, 无凭证 | - |
| 企业微信 | WS/URL回调 | 群聊@bot, 专用群 |
| QQ | 扫码/WS/URL三模式 | AppSecret不可明文 |
| 飞书 | 自建应用 | 权限+事件订阅 |
| 钉钉 | Bot创建 | 发布审核流程 |
| 元宝派 | 扫码+AppID/Secret | 社区派 |

## 安全

- 敏感操作(文件删除/系统配置修改/命令执行) → 用户在手机IM内审批确认，不是电脑弹窗
- 多层来源校验
- 绑定身份：关联账号，支持灵活换绑

## 实现文件

```
src/main/services/im-bridge.ts    - IM桥接服务
src/main/services/adaptors/       - 各平台适配器
src/components/AssistantPanel.tsx  - 助理执行记录页面
```

## 验收标准

- [ ] 微信Bot扫码绑定 → 助理Tab显示绿色已连接
- [ ] 手机微信发"帮我写周报" → 自动生成 → 结果推回微信
- [ ] 敏感操作 → 手机IM收到审批请求 → 确认后执行
- [ ] 企业微信群聊@bot → 执行 → 结果推回群聊
- [ ] 解绑某平台 → 其他平台不受影响
