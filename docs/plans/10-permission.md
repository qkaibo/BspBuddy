# 10 — 权限与安全沙箱 (Permission Modes)

> 对应 SPEC: `specs/From-Beginner-to-Expert-Guide/Permission-Modes.md`
> Status: ❌ P3 待开发

## 功能概要

默认权限和完全访问权限两种模式。默认权限下，AI 在工作空间内高效执行任务，但高风险操作(敏感路径写入/重要删除/脚本命令/网络)会暂停请求确认。

## 权限 UI 位置

新建任务输入框下方，点击「默认权限」下拉菜单切换（不是顶栏或其他位置）。

## 默认权限保护的操作

| 操作类型 | 说明 |
|----------|------|
| 写入受保护/敏感路径 | 避免覆盖密钥、凭据、安全配置 |
| 删除受保护文件/重要目录/批量删除 | 避免误删难恢复的资料 |
| 执行脚本/命令/外部程序 | 可能修改文件、访问网络或影响系统 |
| 网络访问/敏感能力 | 命中安全中心规则或高风险能力时确认 |

## 确认弹窗内容

1. **操作内容**: 写文件/删文件/执行脚本
2. **影响范围**: 路径是否在工作空间内
3. **执行理由**: 这步是否确实必需

取消确认 → 不执行 → Agent 提供替代方案。

## 验收标准

- [ ] 输入框下方下拉菜单 → 默认权限/完全访问权限
- [ ] 切换到完全访问 → 弹窗风险确认
- [ ] 默认权限下 Agent 尝试删除桌面文件 → 确认弹窗
- [ ] 取消确认 → 不执行 → Agent 提供替代方案
- [ ] 工作空间内文件写入 → 自动通过(默认权限)
- [ ] 完全放开用完即关
