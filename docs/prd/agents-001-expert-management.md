## 概述

专家配置管理是 BspBuddy 从「使用专家」到「管理专家」的升级。在保留现有 WorkBuddy 式专家使用体验（浏览→召唤→对话）的基础上，引入 StaffDeck 的专家生命周期管理能力：创建、编辑、上线/下线、绑定技能与知识库、发布广场、测试运行。

参考来源：StaffDeck `prd-001 数字员工管理`、`prd-014 开放广场`。

---

## 用户场景

| 角色 | 场景 | 动机 |
|------|------|------|
| 普通用户 | 创建一个自己的专家，配置人设和技能 | 定制专属 AI 助手 |
| 普通用户 | 从广场复制别人的专家，在此基础上修改 | 快速复用已验证的配置 |
| 普通用户 | 上线/下线专家 | 控制哪些专家在使用列表中可见 |
| 高级用户 | 为专家绑定 SOP 技能和知识库 | 让专家具备专业流程和领域知识 |
| 高级用户 | 编辑专家时 Test Run 测试效果 | 调优配置后再正式使用 |

## 功能清单

| # | 功能 | 关联页面 | 说明 |
|---|------|---------|------|
| 1 | 专家列表管理 | ExpertCenter → 管理 Tab | 查看我的专家（在线/草稿/下线），支持搜索筛选 |
| 2 | 创建专家 | 管理 Tab → 新建 | 输入基础信息后进入完整编辑器 |
| 3 | 编辑专家 | 管理 Tab → 编辑 | 编辑器：基础信息 + 人设 + Test Run（不含资源绑定 Tab） |
| 4 | 管理 SOP | 管理 Tab → 管理 SOP | 设专家 scope → SOP 归属工作台（见 agents-002）；SOP 内容创作见 agents-003 |
| 5 | 上线/下线 | 管理 Tab | 草稿→上线，上线→下线，生命周期切换 |
| 6 | 发布广场 / 取消发布 | 管理 Tab | 控制专家是否出现在广场供他人复制 |
| 7 | 删除专家 | 管理 Tab | 确认后软删除 |
| 8 | 广场浏览 | 使用 Tab → 广场子Tab | 浏览所有公开专家，按分类/名称搜索 |
| 9 | 复制专家 | 广场 → 复制到我的 | 从广场复制专家的完整配置（技能/知识库分支独立） |
| 10 | Test Run | 编辑弹窗 | 在编辑弹窗内测试当前专家配置的对话效果 |

## 数据模型

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|

| persona | string | 是 | 人设 System Prompt |
| methodology | string | 否 | 方法论 |

| skills | string[] | 否 | 现有：技能标签 → 升级为 Skill ID 引用 |
| categories | string[] | 否 | 分类标签 |
| examples | ExpertExample[] | 否 | 任务示例 |
| isCustom | boolean | 是 | 是否为自定义（现有，不动） |

| 字段 | 类型 | 必填 | 说明 |

| sopSkills | string[] | 否 | 绑定的 SOP 技能 ID |

### Expert 生命周期状态机

```

  ↑                    │
  └────────────────────┘ (重新上线)
```

### 布局

```
┌─────────────────────────────────────────────────────────┐
│  ExpertCenter Header（"专家中心"）          [使用/管理] │
├─────────────────────────────────────────────────────────┤
│  [使用]  Tab                               [管理] Tab  │
│  现有内容不动                                ↓          │
│                                         ┌────────────┐ │
│  [我的专家] [专家团] [广场]              │ [管理 Tab]  │ │
│                                         │            │ │
│  ↓ 现有使用体验                          │ [搜索...]  │ │
│                                         │            │ │
│  保持 WorkBuddy 风格                     │ [+ 新建专家]│ │
│                                         │            │ │
│                                         │ ┌────────┐ │ │
│                                         │ │ 专家卡片 │ │ │
│                                         │ │ 姓名 状态│ │ │
│                                         │ │ [编辑]  │ │ │
│                                         │ │ [上线]  │ │ │
│                                         │ │ [广场]  │ │ │
│                                         │ │ [删除]  │ │ │
│                                         │ └────────┘ │ │
│                                         │ ...        │ │
│                                         └────────────┘ │
└─────────────────────────────────────────────────────────┘
```

### 管理 Tab 字段

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| 搜索 | 文本 | 否 | 按专家名称过滤，300ms 防抖 |
| 状态筛选 | 下拉 | 否 | 全部 / 在线 / 草稿 / 已下线 |

### 专家卡片内容

- 头像（首字母）+ 名称 + 头衔
- 状态标签：在线（绿）/ 草稿（蓝）/ 已下线（灰）
- 广场标签：已发布（显示）
- 操作按钮（按状态显示）：

| 按钮 | 显示条件 | 行为 |
|------|---------|------|
| 编辑 | 所有状态 | 打开专家编辑弹窗 |
| 上线 | status === 'draft' 或 'offline' | 确认 → status = 'online' |
| 下线 | status === 'online' | 确认 → status = 'offline' |
| 发布广场 | isOverall === false | 确认 → isOverall = true |
| 取消发布 | isOverall === true | 确认 → isOverall = false |
| 删除 | 所有状态 | ConfirmDialog → 软删除 |

## 页面二：专家编辑弹窗（ExpertEditorModal）

> **规范变更：** SOP / Skill / MCP / 知识库 / 连接器 / 模型绑定 **不在编辑器内**。  
> 绑定流程见 [agents-002](./agents-002-editor-ux.md)（ResourceImportDialog）。

### 布局

```
┌─────────────────────────────────────────────────────────┐
│  编辑专家 — <专家名称>                              [×] │
├──────────────┬──────────────────────────────────────────┤
│ ● 基础信息   │  名称 / 头衔 / 描述 / 头像 / 分类         │
│   人设       │  System Prompt / 方法论                   │
│              │  提示：资源请到「绑定资源」配置             │
│              │  [Test Run]                               │
└──────────────┴──────────────────────────────────────────┘
│ [取消]                              [保存草稿] [上线]   │
└─────────────────────────────────────────────────────────┘
```

### 字段详情

#### 基础信息

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| 名称 | 文本 | 是 | 最长 20 字符 |
| 头衔 | 文本 | 否 | 如「法律咨询专家」 |
| 头像 | 上传/颜色选择 | 否 | 6 色预设 + 自定义上传 |
| 描述 | 多行 | 是 | 描述能力和适用场景 |
| 分类 | 多选标签 | 否 | 预定义分类 + 自定义添加 |

#### 人设

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| System Prompt | 多行 | 是 | 注入到对话上下文的专家人设提示词 |
| 方法论 | 文本 | 否 | 如「SWOT 分析 + 案例研究」 |

### SOP 入口（StaffDeck scope，非编辑器勾选）

```
管理 Tab 专家卡片
  → [管理 SOP]
  → 设当前专家 scope
  → 打开插件 → SOP 工作台（只看该专家已有）
  → [从广场/其他专家复制] → 搜索勾选 → 导入
```

详情见 agents-002。

### Test Run 测试

编辑弹窗底部有 [Test Run] 按钮：

```
点击 [Test Run]
  → 侧面板对话区域
  → 使用当前人设 + 已绑定资源
  → 输入测试消息
  → SSE 流式返回专家回复
  → 可多次测试，不产生持久化会话
```

## 页面三：广场（使用 Tab → 广场子Tab）

### 布局

```
┌─────────────────────────────────────────────────────────┐
│  [使用]  Tab                                          │
│                                                         │
│  [我的专家] │ [专家团] │ [广场]                           │
│             │          │                                 │
│             │          │ ┌─────────────────────────────┐ │
│             │          │ │ [搜索广场专家...] [分类 ▼]    │ │
│             │          │ │                             │ │
│             │          │ │ ┌─────────┐ ┌─────────┐    │ │
│             │          │ │ │ 专家 A   │ │ 专家 B   │    │ │
│             │          │ │ │ 描述...  │ │ 描述...  │    │ │
│             │          │ │ │ [查看]   │ │ [复制到我]│   │ │
│             │          │ │ │ [复制到我]│ │          │    │ │
│             │          │ │ └─────────┘ └─────────┘    │ │
│             │          │ └─────────────────────────────┘ │
└─────────────────────────────────────────────────────────┘
```

### 交互

- 搜索：按名称/头衔过滤，300ms 防抖
- 分类筛选：按 categories 过滤
- 点击卡片 → 展开详情抽屉（名称/头衔/描述/人设/技能列表）
- 详情抽屉支持 [←前] [后→] 导航
- [复制到我] → 创建专家副本到我的专家（status=draft, isOverall=false）
  - 技能/知识库创建分支记录（synced）
  - 后续用户可自定义修改

## API 依赖

| 端点 | IPC Channel | 说明 |
|------|------------|------|
| 专家列表 | `expert:list` | 获取所有专家（现有） |

| Test Run | `expert:test-run` | 测试专家配置（新增） |

## 页面关系

| 从 | 到 | 触发 | 说明 |
|----|-----|------|------|
| ExpertCenter → 管理 Tab | 专家编辑弹窗 | 点击编辑 | 打开 ExpertEditorModal（基础+人设） |
| ExpertCenter → 管理 Tab | PluginPanel → SOP | 点击管理 SOP | 设 scope 并打开工作台 |
| SopSkillsPanel | ResourceImportDialog | 从广场/其他专家复制 | 导入到当前 scope |
| ExpertCenter → 使用 Tab → 广场 | 专家编辑弹窗 | "复制到我" | 复制后自动打开编辑 |
| ExpertCenter → 使用 Tab → 广场 | 使用 Tab → 我的专家 | 复制成功后 | 新专家出现在我的专家列表 |

## 验收标准

- [ ] 管理 Tab 显示所有我创建的专家，支持按状态筛选
- [ ] 创建专家 → 填写基础信息 → 保存草稿 → 出现在列表（status=draft）
- [ ] 编辑专家仅改基础信息/人设并保存；资源绑定走「绑定资源」（见 agents-002）
- [ ] 管理列表展示绑定摘要，导入 SOP 后数量更新
- [ ] 点击上线 → status 变为 online → 出现在使用 Tab 的我的专家列表
- [ ] 点击下线 → status 变为 offline → 在使用 Tab 中隐藏
- [ ] 发布广场 → isOverall=true → 出现在广场列表
- [ ] 广场中复制专家 → 创建独立副本，技能/知识库建立分支关系
- [ ] Test Run 使用当前人设 + 已绑定资源配置测试对话效果
- [ ] 上线后的专家在使用 Tab 中可召唤，注入人设 + SOP + 知识库上下文
- [ ] 删除专家 → ConfirmDialog 确认 → 软删除（保守，恢复期后物理删除）
